# Formorix-Terminologie

Die deutschen Formorix-Bezeichnungen ergänzen Orcas bestehendes Glossar. Marken, Materialnamen, Einheiten und technische Kennungen bleiben unverändert.

| Englisch | Deutsch | Bedeutung |
| --- | --- | --- |
| Hybrid preview | Hybrid-Vorschau | Gemeinsame räumliche Vorschau der Orca-Kernbahnen und der nichtplanaren Oberflächenbahnen; kein synchronisierter Druckauftrag. |
| Orca core paths | Orca-Kernbahnen | Tatsächliche konventionelle Extrusionsbahnen des berechneten Kerns. |
| Shared interfaces | Gemeinsame Grenzflächen | Geometrische Grenze zwischen Kern und Schale. |
| Missing underlay | Fehlende Auflage | An einem Prüfpunkt fehlt nominaler Kontakt zu einer konventionellen Extrusionsbahn. |
| Unverified regions | Ungeprüfte Bereiche | Ein ausreichender geometrischer Nachweis liegt nicht vor. |

Die Zuordnung **Hybrid preview → Hybrid-Vorschau** ist ebenfalls im lokalen Orca-Wiki-Glossar eingetragen. Diese versionierte Seite hält die Formorix-Ergänzung im eigenen Repository verfügbar; das fremde Orca-Wiki wird durch diesen Auftrag nicht veröffentlicht.
