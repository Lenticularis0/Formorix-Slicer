# Übergänge zwischen Druckköpfen

Diese Einstellungen beschreiben gespeicherte Fertigungswünsche. Sie beeinflussen die erste Einzelkopf-Vorschau noch nicht.

| Übergang | Bedeutung |
| --- | --- |
| Feste Grenze | Jeder Kopf bleibt in seinem zugewiesenen Bereich. |
| Verwoben | Eine Übergangszone soll die Bereiche verzahnen oder schichtweise ineinandergreifen lassen. Breite, Überlappungsgrad und Muster sind einstellbar. |
| Parallele Bahnen | Zwei Köpfe sollen später dicht nebeneinander den gemeinsamen Bereich bearbeiten. |

Eine physisch durchgehende Extrusionsbahn über eine Grenze erfordert denselben Kopf. Mit verschiedenen Köpfen müssen später Verbindung, Materialhaftung, Abstand und Kollisionsfreiheit geprüft werden. Die GUI zeigt deshalb den Status **nicht geprüft**. Es entstehen weder Verwobungsgeometrie noch parallele Mehrkopf-Bahnen.
