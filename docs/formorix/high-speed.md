# High-Speed-Modus

Der Editor prüft als erste Voraussetzung, ob drei aktivierte Köpfe mit kompatiblen PETG-Profilen und überlappenden Temperaturbereichen konfiguriert sind. Identische Profile und verschiedene kompatible PETG-Profile werden unterschieden.

Die Strategie wird im Projekt gespeichert. Sie erzeugt noch keine Arbeitsaufteilung und verkürzt die geschätzte Zeit der Einzelkopf-Vorschau nicht. Eine technische Freigabe erfordert Materialabstimmung, Kalibrierung, Maschinenkinematik, Kollisionsprüfung und eine zeitliche Planung. Der Status bleibt bis dahin ungeprüft.
